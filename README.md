# 珠海 · 大吃特吃

一份共享的「吃到哪了」清单。

## 用法

打开页面 → 点菜名打勾 → 每条可以填地址 → 自动同步。
换设备打开同一个链接，看到的是一样的进度。

## 机制

- 清单状态存在一个 **secret Gist**（不随仓库公开；仓库里没有数据文件）
- 勾选与删除用 `±毫秒时间戳` 编码：正数 = 勾上，负数 = 取消（按绝对值取新）
- 地址是 `{t, v}`：按 `t` 取新；清空写空值墓碑，删除条目同时写地址/勾选墓碑，避免并集复活
- 推送前先拉远端做一次合并（旧版页面整份覆盖时地址能捞回来），再整份写回
- 页面每 5 秒拉一次，带 `If-None-Match`，304 不计额度
- 正在编辑地址栏时不重建列表，失焦后补渲染；「减少动效」下删除动画直接跳过
